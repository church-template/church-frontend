### 📌 작업 개요
네이버·구글 검색엔진 노출을 위한 SEO 기반 작업. 메타데이터·구조화데이터·sitemap·RSS를 코드에 반영하고, 검색엔진 콘솔 등록 절차를 문서화

### 🎯 구현 목표
- 공개 페이지에 title·description·canonical·OG/Twitter 카드 적용
- 검색엔진 소유확인(구글 서치콘솔·네이버 서치어드바이저) 메타태그 자리 마련
- 회원 전용 영역(설교·갤러리·챌린지·차량운행·마이페이지)은 검색 수집에서 제외
- sitemap·RSS로 신규 콘텐츠(공지·행사)를 검색엔진이 발견할 수 있도록 구성
- 구조화데이터(JSON-LD)로 교회·공지·행사 정보를 명시적으로 제공

### ✅ 구현 내용

#### 검색엔진 소유확인 메타태그
- **파일**: `src/app/layout.tsx`, `.env.example`
- **변경 내용**: `GOOGLE_SITE_VERIFICATION`·`NAVER_SITE_VERIFICATION` env 값이 있을 때만 `verification` 메타태그 출력
- **이유**: 값 미설정 시(CI·로컬) 태그 자체가 안 나가 빌드에 영향 없음. 실제 값은 서치콘솔·서치어드바이저에서 발급 후 Vercel 대시보드에 등록해야 함

#### 공개 페이지 metadata·canonical 일괄 적용
- **파일**: `about/*`, `worship`, `bulletins`, `notices`, `events`, `departments` 등 공개 페이지 `page.tsx`
- **변경 내용**: 각 페이지에 `generateMetadata`(또는 정적 `metadata`)로 title·description·canonical URL 부여
- **이유**: root layout에는 canonical을 두지 않는다 — 전 페이지가 홈을 정본으로 가리키는 SEO 버그를 방지하기 위해 페이지별로 개별 지정

#### 회원 전용 영역 검색 수집 제외
- **파일**: `src/app/robots.ts`, `sermons`·`gallery`·`challenges`·`vehicle-runs`·`mypage` 관련 `page.tsx`
- **변경 내용**: robots.txt에서 회원 전용 경로 차단 + 해당 페이지에 `robots: { index: false }`(noindex) 이중 적용
- **이유**: 비로그인 사용자에겐 로그인 안내만 보여 검색 가치가 없는 페이지라, sitemap 진입 자체를 막고 페이지 메타에도 재확인 차단을 걸어 실수로 노출되는 걸 방지

#### 공지·행사 상세 검색 메타·구조화데이터
- **파일**: `src/app/(site)/notices/[id]/page.tsx`, `events/[id]/page.tsx`, `ArticleJsonLd`·`EventJsonLd` 컴포넌트, 마크다운 스트립·요약 헬퍼
- **변경 내용**: 본문 마크다운을 스트립해 요약 description으로 사용, `Article`/`Event` 타입 JSON-LD 삽입
- **이유**: 검색결과 스니펫 품질 향상 + 리치 결과(이벤트 등) 노출 가능성 확보

#### sitemap 동적 확장
- **파일**: `src/app/sitemap.ts`
- **변경 내용**: 정적 공개 라우트 + 부서 상세(상수 구동) + 공지·행사 상세를 API로 페이징 수집해 sitemap에 포함. 백엔드 실패 시 정적 엔트리만 반환(폴백), 500건 안전 상한, 24시간 재생성
- **이유**: 신규 공지·행사가 자동으로 검색엔진에 발견되도록 하되, 백엔드 장애가 빌드/사이트맵 전체를 깨뜨리지 않게 방어

#### RSS 피드 추가
- **파일**: `src/lib/rss.ts`, `src/app/rss.xml/route.ts`(라우트)
- **변경 내용**: 공지·행사를 RSS 2.0 XML로 노출하는 순수 함수(`buildRssXml`)와 route handler 추가
- **이유**: 네이버 서치어드바이저가 sitemap 외에 RSS 제출을 지원 — 콘텐츠 수집 보조 채널로 활용

#### Church 구조화데이터 보강
- **파일**: `src/components/seo/ChurchJsonLd.tsx`, `src/constants/church.ts`
- **변경 내용**: 주소를 세분화 필드로 나누고 `CHURCH_GEO`(위도·경도) 자리를 추가(현재 `null`)
- **이유**: 지역 검색 리치 결과 대응. 좌표는 네이버 스마트플레이스·구글 비즈니스 프로필 등록 후 발급받아야 채울 수 있어 자리만 마련

#### SEO 운영 가이드 문서화
- **파일**: `docs/seo-operations.md`
- **변경 내용**: 소유확인 등록 → sitemap/RSS 제출 → 지역 검색(스마트플레이스·비즈니스 프로필) 등록까지 코드 밖 수동 절차를 순서대로 정리
