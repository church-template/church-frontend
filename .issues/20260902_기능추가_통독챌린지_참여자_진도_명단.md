# ⚙️ [기능추가][통독챌린지] 챌린지 참여자 진도 명단 표시

## 📝 현재 문제점

- 챌린지 상세는 **내 진행만** 보여준다(`TodayBand` + `ReadingCalendar`). 같은 챌린지를 함께 하는 교인이 어디까지 읽었는지 알 수 없다.
- 혼자 읽는 화면이라 통독을 이어갈 동기(함께 읽는 감각)가 화면에 드러나지 않는다.
- 미참여자에게도 "참여하면 무엇이 보이는지"가 없어 참여 유인이 약하다.

## 🛠️ 해결 방안 / 제안 기능

- 챌린지 상세 달력 아래에 **함께 읽는 사람들 명단 섹션**을 추가한다. 진도순 정렬이되 **순위 숫자는 표시하지 않는다**(경쟁이 아니라 동행).
- 한 줄 = 이름 + 현재 위치(권·장) + 진도바·%. 회독 완료자는 `N회독` 배지로 구분한다.
- **참여자에게만** 노출한다. 미참여자에게는 명단 대신 안내 한 줄만 보여준다(요청 자체를 보내지 않아 403이 발생하지 않는다).
- 새 라우트·새 UI 컴포넌트를 만들지 않는다. 진도바는 `TodayBand`의 2-div 패턴, 페이지네이션은 기존 `common/Pagination`을 재사용한다.

> 선행 의존: 백엔드 `GET /api/bible-challenges/{id}/participants` (church-backend 이슈)
