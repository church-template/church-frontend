# 🚀 [기능개선][SEO] 네이버·구글 검색엔진 최적화

## 📝 현재 문제점

- 구글 서치콘솔·네이버 서치어드바이저에 사이트가 등록되어 있지 않아 검색 노출 현황을 확인·관리할 수 없다
- 공지·주보·행사·예배안내·오시는길·부서 등 일부 공개 페이지에 검색용 메타 정보(제목·설명)가 없다
- 공지·설교·행사 상세 페이지가 사이트맵에 포함되지 않아 개별 글이 검색에 수집되지 않는다
- 페이지별 정본 URL(canonical) 표기가 없어 중복 URL이 생기면 검색 평가가 분산될 수 있다
- 지역 검색(예산·삽교 지역 키워드) 노출을 위한 위치 정보 보강·플레이스 등록이 되어 있지 않다

## 🛠️ 해결 방안 / 제안 기능

- 브랜드 검색(교회명), 지역 키워드, 콘텐츠 검색(설교·공지·행사) 노출을 목표로 검색엔진 최적화 진행
- 검색엔진 소유확인 준비, 누락 메타 정보 보강, 사이트맵 확장, 구조화 데이터 확장, RSS 제공
- 서치콘솔·서치어드바이저·플레이스 등록 절차를 운영 가이드 문서로 정리해 코드 밖 등록 작업을 지원

## ⚙️ 작업 내용

- 구글·네이버 사이트 소유확인 메타태그 자리 마련
- 누락 공개 페이지 메타 정보(제목·설명·OG) 보강 및 상세 페이지 동적 메타 적용
- 전 공개 페이지 canonical URL 적용
- 사이트맵에 공지·설교·행사 상세 URL 포함
- 구조화 데이터 확장(교회 위치 정보 보강, 콘텐츠별 스키마)
- RSS 피드 제공(네이버 웹문서 수집 보조)
- 검색엔진·플레이스 등록 운영 가이드 문서 작성
